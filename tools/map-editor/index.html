其他语言 JSON

每行一条命令。奖励可写 disable axiom a3 / give key red；门可写 require key red / enable axiom a3。钥匙按模块实例隔离；禁用公理也禁止依赖它的宏和过门证明。

脚本命令参考

每行一条命令，也可用分号分隔；// 开头的整行是注释。文字使用 JSON 双引号，ID 不含空格。下列 ID、金额和文字可替换：

require key red
require not-key red
require flag ready
require not-flag ready
require reward prize
require money >= 10
require count visits >= 2
give key red
take key red
give money 10
take money 10
set flag ready
clear flag ready
set count visits 0
add count visits 1
disable axiom a3
enable axiom a3
unlock reward prize
unlock layer T-layer
open gate door
close gate door
set tile door road
set text door "新的文字"
message "你好"

比较符：>=、<=、==、!=、>、<。格子类型：road / wall / gate / reward / ordinal；层：D-layer / T-layer / P-layer / G-layer。具体语法由公共解析器校验，不支持 JavaScript 或 eval。

门的 require 条件每次进入都会检查；效果默认每个具名格执行一次。需要重复效果时，在其他 data JSON 中设置 "scriptRepeat": true。

p / d / t / td / never、getD / payD、unl.layer、dstrTarget / requiresReward 等元数据直接写入 JSON，保留现有字段。
