## 定理
定理是一个线性表，包含断言、假设、步骤三部分。这里暂时不介绍断言。假设和步骤都叫做定理。
### 假设
假设由用户添加，只要是合法wff即可，可以是0条或多条。
### 步骤
每个步骤要么由使用规则推理得到，要么由内联元规则得到。我们先介绍规则。

## 规则
规则由断言、假设、结论三部分组成。此外可能还带由中间步骤信息。使用规则推理即：给定假设对应的定理，若检查断言通过，则向定理表添加结论作为新的定理。
### 规则名的约定
每个规则都有确定的名称，用户定义的规则除了定义外，不能以字母a、d、符号开头
系统规则的命名约定为：公理以a开头、定义以d开头、系统定理以.开头。

### 步骤
根据中间推导步骤，规则分三类：
1. 公理，如mp、a1、asep、d&，特点是没有中间推导步骤；

axiom a1: $1→$2→$1;
axiom a2: ($1→$2→$3)→($1→$2)→($1→$3);
axiom a3: (¬$1→¬$2)→($2→$1);
axiom a4: ∀$x:$0→#sb($0,$x,$A);
axiom a5: ∀$x:($0→$1)→∀$x:$0→∀$x:$1;
axiom a6: nf($0,$x); $0→∀$x:$0;
axiom a7: $A=$A;
axiom a8: $A=$B→#sb($0,$x,$A)→#sb($0,$x,$B);

2. 定理，如.t、.Erp；
3. 快速元定理（多数由已知规则加上前缀生成，如对应之前的ecv<>，另外还有自动计算四则运算等递归定理，如.100+100），无中间步骤，但可以按需展开（组合元例外：它永远都会自动展开，否则无法生成）。展开过程由系统硬编码。

## 内联元规则
内联元规则是定理的一种步骤，均为按需展开。
条件：引入假设$1，经若干推理得到$2后（可自动选择外面的带$1>$0的定理当成$0用），自动生成$1>$2。
概括：引入变量$1，经若干推理得到$2后（可自动选择外面的带V$1:$0的定理当成$0用），自动生成V$1:$2。
存在：选择一个形如E$1:$0的定理，引入全新的局部常量%1，把该定理当成用#sb($0,$1,%1)，经若干推理得到$2后，自动生成E$1:#sb($2,%1,$1)。
互推：选择一个定理和一个形如|-$a<>$b的推理规则，指定替换的位置（可多个，甚至支持手点），一步生成替换后的定理。
命题完备：根据用户自动生成纯命题逻辑公理。
## 证明助手：
先引入一个要证明的目标$1定理做假设，然后倒着写步骤，把没输入的条件作为新的目标，所有目标终结了就生成$1。未证明的目标会特殊标记（黄底），目标标上黄框。

## 替换函数#sb
该函数对 #sb(a, b, c, D) 形式的表达式进行化简，其中 a 为被替换的主体，b 为源变量，c 为目标表达式，D 为约束变量集合（替换时跳过 D 中的变量）。化简过程按顺序尝试以下规则，一旦匹配即应用并停止。

1. 直接变量替换
   条件：a 是原子变量且 a == b，且 Γ 可证 b 不在 D 中（即 nf b D 为真）。
   操作：若 Γ 可证 c 的所有自由变量都在 D 中（即 of c D 为真），则将整个表达式替换为 c；否则报错（因为会引入未被约束的自由变量）。
   公式：当 Γ ⊢ nf b D 且 Γ ⊢ of c D 时，#sb(a,b,c,D) -> c。

2. 恒等或可忽略替换
   条件满足以下任一：
   - a 是常量（非变量，如 '0' 或大写字母开头）；
   - c 与 b 相同（即 c == b）；
   - Γ 可证 b 不在 a 中自由出现（除非在 D 中），即 Γ ⊢ nf a b D。
   操作：直接删除外层 #sb，保留 a 不变。
   公式：#sb(a,b,c,D) -> a。

3. 结构分配（逻辑、谓词、函数）
   条件：a 是逻辑连接词（如 &, |, ->）、谓词应用或函数应用。
   操作：将 #sb 递归分配到 a 的每一个子项中。
   公式：#sb(f(t1,...,tn), b, c, D) -> f(#sb(t1,b,c,D), ..., #sb(tn,b,c,D))。

4. 量词与类构造引入新约束
   条件：a 是量词（∀ 或 ∃）或类构造表达式（如 {x | φ}）。
   操作：将该构造绑定的变量 x 加入 D，然后递归处理该构造的内部主体。
   公式：#sb(Qx. a1, b, c, D) -> Qx. #sb(a1, b, c, D ∪ {x})。

5. 约束集合的精简
   条件：对于 D 中的某个变量 x，Γ 可证 x 既不出现在 b 中，也不自由出现在 c 中（即 Γ ⊢ nf b {x} 且 Γ ⊢ nf c {x} 成立）。
   操作：从 D 中移除 x，因为该约束实际上不影响替换。
   公式：若 Γ ⊢ nf b x 且 Γ ⊢ nf c x，则 #sb(a,b,c,D) -> #sb(a,b,c,D \ {x})。

6. 嵌套替换的交换化简
   条件：a 本身是一个替换表达式 #sb(a1, b1, c1, D1)，且 Γ 可证外层源变量 b 不在 a1 中自由出现（除非受外层约束 D 保护），即 Γ ⊢ nf a1 b D。
   操作：将外层替换分配到内层目标 c1 中，即先用外层替换处理 c1，再将整个内层替换变为 #sb(a1, b1, #sb(c1, b, c, D), D1)。
   公式：若 Γ ⊢ nf a1 b D，则 #sb( #sb(a1, b1, c1, D1), b, c, D ) -> #sb( a1, b1, #sb(c1, b, c, D), D1 )。

7. 回退保留原样
   条件：以上所有规则均不适用。
   操作：保留原始 #sb 结构不变，不再进行任何化简。

注意：所有判定都依赖已知前提 Γ，通过原子断言求解器进行验证。如果某个条件无法证明，则视为不成立，继续尝试后续规则。该函数保证化简结果的正确性，若某步可能引入错误（如情况1中目标表达式含有未被约束的自由变量）则立即报错，而非继续。



## 断言
断言是用于限制元变量的取值的。有以下三种断言：（用小写字母表示任意表达式，大写字母表示变量的集合）
- nf a B C : B中的所有变量都不在Vc1:Vc2....Vcn:a中自由出现（其中c1...cn是集合C中的所有变量）
- of a B : a中只能有出现在集合B中的自由变量
- dt A : A中的变量互不相同
某些规则在执行前会检查相关断言。断言nf与of会根据以下规则变成原子断言：
1. 不涉及量词与约束变量、不涉及#sb函数时的函数、逻辑连词、谓词均可分配，如：
nf a>b B C <=> nf a B C & nf b B C 
2. 若a为原子命题的普通变量或常量，则所有nf、of断言无条件成立。
3. 涉及量词时，nf与of的行为有所不同，nf为将量词纳入第三个参数的集合后分配，of为纳入第二个参数的集合后分配：
- nf Vx:a B C <=> nf a B CU{x}
- of Vx:a B <=> of a BU{x}
4. 涉及#sb函数时，首先尝试化简#sb函数，无法化简时只能认为该断言未知从而失败，但下列特殊情况例外：
- nf c b & nf b D => nf #sb(a,b,c,D) b
- ??(a) & ??(c) => ??(#sb(a,b,c,D))  其中??是nf或of断言，处第一个参数括号中指定外，剩下的参数可任取


定理列表中可前置添加一系列的原子断言（即关于元变量和普通变量的断言），原子断言有三种：（用小写字母表示变量，大写字母表示变量的集合）
- nf a B C :  a!@B || a@C || a=0
- of a B : a@B || a=0
- dt A : forall i,j: ai!=aj
它们的否定为
- of a B & a!=c & a!=0 : a@B && a!@C && a!=0
- nf a B & a!=0: a!@B && a!=0
- ex A : exists i,j: ai=aj

constrain设为属于、不属于、nf、of、dt、ex四种
