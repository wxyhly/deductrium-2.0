## 定理
定理是一个线性表，包含断言、假设、步骤三部分。这里暂时不介绍断言。假设和步骤都叫做定理。
### 假设
假设由用户添加，只要是合法wff即可，可以是0条或多条。
### 步骤
每个步骤要么由使用规则推理得到，要么由内联元规则得到。我们先介绍规则。

## 规则
规则由断言、假设、结论三部分组成。此外可能还带由中间步骤信息。使用规则推理即：给定假设对应的定理，若检查断言通过，则向定理表添加结论作为新的定理。
### 规则名的约定
每个规则都有确定的名称，用户定义的规则除了定义外，不能以字母a、d、符号开头
系统规则的命名约定为：公理以a开头、定义以d开头、系统定理以.开头。

### 步骤
根据中间推导步骤，规则分三类：
1. 公理，如mp、a1、asep、d&，特点是没有中间推导步骤；

axiom a1: $1→$2→$1;
axiom a2: ($1→$2→$3)→($1→$2)→($1→$3);
axiom a3: (¬$1→¬$2)→($2→$1);
axiom a4: ∀$x:$0→#sb($0,$x,$A);
axiom a5: ∀$x:($0→$1)→∀$x:$0→∀$x:$1;
axiom a6: nf($0,$x); $0→∀$x:$0;
axiom a7: $A=$A;
axiom a8: $A=$B→#sb($0,$x,$A)→#sb($0,$x,$B);

2. 定理，如.t、.Erp；
3. 快速元定理（多数由已知规则加上前缀生成，如对应之前的ecv<>，另外还有自动计算四则运算等递归定理，如.100+100），无中间步骤，但可以按需展开（组合元例外：它永远都会自动展开，否则无法生成）。展开过程由系统硬编码。

## 内联元规则
内联元规则是定理的一种步骤，均为按需展开。
条件：引入假设$1，经若干推理得到$2后（可自动选择外面的带$1>$0的定理当成$0用），自动生成$1>$2。
概括：引入变量$1，经若干推理得到$2后（可自动选择外面的带V$1:$0的定理当成$0用），自动生成V$1:$2。
存在：选择一个形如E$1:$0的定理，引入全新的局部常量%1，把该定理当成用#sb($0,$1,%1)，经若干推理得到$2后，自动生成E$1:#sb($2,%1,$1)。
互推：选择一个定理和一个形如|-$a<>$b的推理规则，指定替换的位置（可多个，甚至支持手点），一步生成替换后的定理。
命题完备：根据用户自动生成纯命题逻辑公理。
## 证明助手：
先引入一个要证明的目标$1定理做假设，然后倒着写步骤，把没输入的条件作为新的目标，所有目标终结了就生成$1。未证明的目标会特殊标记（黄底），目标标上黄框。

## 替换函数#sb
#sb函数是个特殊的系统函数，它的格式为#sb(a,b,c,D)。其中a可以是任意表达式，b是变量，c是项，D是变量的集合。#sb(a,b,c,D)的含义为：在D中变量的约束下，将a中的所有b替换为c。具体计算规则根据断言情况而定：
- 若断言nf a b D成功或b=c(完全相等，不模糊匹配)，则#sb(a,b,c,D) <=> a
- 若a=b(完全相等，不模糊匹配)，且断言nf a D成功，则又分两种情况：若断言nf c D成功，则#sb(a,b,c,D) <=> c，若失败则断言失败（意味着整个#sb函数非法）。
- 否则不计算，但遇到下面的情况系统会自动分配或化简：
1. 不涉及量词与约束变量、不涉及#sb函数时的函数、逻辑连词、谓词均可分配，如：
#sb(a>b,c,d,E) <=> #sb(a,c,d,E)>#sb(b,c,d,E)
2. 若a为原子命题的普通变量或常量，则不替换，即#sb(a,b,c,D) <=> a
3. 若a涉及约束变量，则分配进去，同时将约束变量加入变量集合中，：
#sb(Vx:a,b,c,D) <=> Vx:#sb(a,b,c,DU{x})
4. 可移除约束变量集合中替换的源和目标中都不自由出现的变量，即若断言nf b D & nf c D成立，则#sb(a,b,c,E) <=> #sb(a,b,c,E\D)
4. 若a本身也是#sb函数（设a=#sb(a1,b1,c1,D1)），则遇到下面的特殊情况会化简：
- 若断言nf a1 b2成立，则#sb(#sb(a1,b1,c1),b2,c2) <=> #sb(a1,b1,#sb(c1,b2,c2))



## 断言
断言是用于限制元变量的取值的。有以下三种断言：（用小写字母表示任意表达式，大写字母表示变量的集合）
- nf a B C : B中的所有变量都不在Vc1:Vc2....Vcn:a中自由出现（其中c1...cn是集合C中的所有变量）
- of a B : a中只能有出现在集合B中的自由变量
- dt A : A中的变量互不相同
某些规则在执行前会检查相关断言。断言nf与of会根据以下规则变成原子断言：
1. 不涉及量词与约束变量、不涉及#sb函数时的函数、逻辑连词、谓词均可分配，如：
nf a>b B C <=> nf a B C & nf b B C 
2. 若a为原子命题的普通变量或常量，则所有nf、of断言无条件成立。
3. 涉及量词时，nf与of的行为有所不同，nf为将量词纳入第三个参数的集合后分配，of为纳入第二个参数的集合后分配：
- nf Vx:a B C <=> nf a B CU{x}
- of Vx:a B <=> of a BU{x}
4. 涉及#sb函数时，首先尝试化简#sb函数，无法化简时只能认为该断言未知，但下列特殊情况例外：
- nf c b => nf #sb(a,b,c,D) b


定理列表中可前置添加一系列的原子断言（即关于元变量和普通变量的断言），原子断言有三种：（用小写字母表示变量，大写字母表示变量的集合）
- nf a B C : a不属于B或a属于C
- of a B : a属于B
- dt A : A中的变量互不相同
