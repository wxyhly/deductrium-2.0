# 旧版 PA 定理迁移

旧官方 `src/fs/initial.ts` 的皮亚诺算数派生定理实际共 **27 条**，已全部迁移到 `src/hs/core/peano-proofs.ts`，通过 `peanoTheorems` 导出新引擎可重放的 `规则名:前提⊢结论;命令;` 文本。

保留原名称、元变量名称、自然数前提和公式结合顺序。旧 `@N`、`>`、`&`、`V`、`E` 分别改用 `∈ℕ`、`→`、`∧`、`∀`、`∃`。特别地，`.<=t` 仍有五个显式前提，`.pred` 仍为全称量化命题。

| 类别 | 已迁移规则 |
| --- | --- |
| 后继、前驱 | `.=Se`、`.=Si`、`.=S`、`.pred` |
| 加法 | `.0+`、`.S+`、`.+@N`、`.+s`、`.+a`、`.+e`、`.+=0` |
| 序关系 | `.<=i`、`.<=s`、`.<=t`、`.<=+`、`.+n<=`、`.<=\|>=` |
| 乘法 | `.0*`、`.*@N`、`.S*`、`.*s`、`.*+d`、`.+*d`、`.*a`、`.*=0`、`.*n=0`、`.*e` |

所有派生规则都有证明命令，不含 `:ax:`。证明只依赖一阶经典逻辑及 `apn1`–`apn5`、`d+1`、`d+2`、`d*1`、`d*2`、`d<=`；不需要 ZFC 或自然数的集合实现。

内部 `Proof` 构造器生成命令和命题编号。归纳通过 `apn5`，存在量词通过 `a4`、`d\e` 和经典逻辑推导。局部参数、归纳变量和新鲜见证限定在命令作用域中；量词改名显式使用全称实例化，避免假设 AST 比较支持 alpha 等价。

等式替换采用基础 `a8` 加两次 `mp`，不生成含未归约 `#sb` 假设的 `<<a8` 元规则。函数项参数需要主线的 `AST.becomeItem` 大写函数兼容修复。

编译项目后运行：

```text
node test/test-peano-proofs.mjs
```

测试直接导入 `js/`，通过真实 `HSLayer.addRules` 在纯逻辑＋PA环境及完整 `initialCreativeRules` 两处重放全部 27 条，并使用独立声明表逐一核对结论、显式前提和额外断言。负例覆盖结论篡改及缺少 `apn5` 时归纳证明必须失败。测试不依赖 TypeScript 加载钩子、外部 checkout、临时文件或浏览器 DOM。
